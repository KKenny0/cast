# Adaptive open-source showcase

This showcase uses two entirely owned fixtures to prove that evidence shape, rather than a fixed template, selects the story.

- `Relay Atlas` is an evidence-rich launch fixture. It produces four cards: judgment, evidence, capability, and case.
- `Threadpack` is a CLI fixture. It produces three cards: problem/input, command/control, and output/use.

The product names, interface records, commands, and output screens are fictional and owned by this repository. They are not compatibility or performance claims. The renderer creates temporary evidence PNGs, binds every final artifact through Visual Job v3, runs the normal renderer and checker path, verifies 2160×2880 output, enforces a 5 MiB seven-image budget, and transactionally publishes only the final PNGs plus the manifest.

Run:

```powershell
node showcases/open-source-tool/render.mjs
```

K3, Repomix, and other third-party material are for local manual acceptance only and must not enter this showcase, its manifest, or the packaged skill.
